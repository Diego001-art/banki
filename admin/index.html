Первая настройка

Нужна один раз. Админка сохраняет изменения прямо в репозиторий сайта на GitHub, поэтому ей нужен ключ доступа. Ключ будет зашифрован паролем.

  1. Откройте создание ключа на GitHub.
  2. Название — любое, срок — 1 год.
  3. Repository access → Only select repositories → banki.
  4. Permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте ниже.
Не короче 12 символов. С этим паролем вы будете входить с любого устройства.

Банки и предложения

Выберите банк, чтобы изменить его карточку и продукты. Продукт попадает на сайт, когда включён «Показывать на сайте». Пока у вида продукта нет ни одного включённого предложения, сайт показывает список банков со ссылкой на их сайты.
