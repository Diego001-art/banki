# Правила для агентов (Claude Code и др.)

Источник требований — `ТЗ.md`. Главное ограничение владельца: **визуальный стиль сайта не меняется** (токены, сетка, компоненты в `src/styles/site.css`).

## Контент и данные
- Не придумывать банки, партнёрства, тарифы, ставки, локальные факты, источники, юридические сведения, отзывы и рейтинги.
- Условие продукта показывается только через публикационный шлюз `src/lib/eligibility.ts`: статус `published`, первичный источник, дата проверки, срок актуальности, подтверждение редактора; при ставке — диапазон ПСК.
- Нет источника — поле скрывается, а не заполняется оценкой.
- Городская страница индексируется только после шлюза (`cityBlockers`): редактор, дата проверки, подтверждённый спрос, локальные факты с источниками, опубликованные предложения в городе. Одно название города — не повод для индексации.
- Тексты согласий и политики — проекты; не выдавать их за готовые юридические документы.

## Персональные данные
- Релиз 1 — без форм и сбора ПДн. Не добавлять формы, аналитику, пиксели, записи сессий без отдельного решения (`docs/privacy-data-map.md`).
- Не писать ПДн в логи, тестовые фикстуры, аналитические события, URL и репозиторий.

## Изменения
- Перед изменением схемы данных (`src/lib/schemas.ts`) описать миграционный риск: какие файлы `data/*.json` и админка затрагиваются.
- Перед выпуском: `npm run validate`, `npm test`, `npm run build` (включает SEO-проверку `scripts/build-sitemap.ts`: noindex, canonical, h1, title, sitemap).
- Индексацию (`data/site.json → indexing`) включает только владелец после юридической проверки и заполнения реквизитов оператора.
