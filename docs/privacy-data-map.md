# Карта данных (заполнить до любой формы)

## Релиз 1 — текущее состояние
- Формы и сбор персональных данных: **нет**.
- Хранилище браузера: `localStorage.city` — выбранный город.
- Сторонние запросы из браузера: при `geoLookup: true` — ipapi.co, запасной ipwho.is (получают IP-адрес посетителя). Сервисы за пределами РФ: нужна правовая оценка (IP-адрес может считаться персональными данными; трансграничная передача). Отключается в `data/site.json` (`geoLookup: false`).
- Шрифты и скрипты — с собственного сайта (без Google Fonts и CDN).
- Аналитика: нет. Яндекс Метрика — только после настройки приватности, без ПДн и без записи полей форм.
