# Чек-лист запуска

## Реквизиты и право
- [ ] Заполнен `data/site.json → operator` (наименование, ИНН, ОГРН/ОГРНИП, адрес, e-mail, ответственный за ПДн).
- [ ] Определена коммерческая модель; если есть партнёрские ссылки — текст раскрытия.
- [ ] Юрист проверил раскрытия, рекламные формулировки (ст. 28 закона о рекламе), применимость ст. 5 закона о потребкредите, политику и cookies.
- [ ] Подтверждено право использовать наименования банков и ссылки.
- [ ] Решён вопрос с определением города по IP (`geoLookup`).

## Контент
- [ ] Кредиторы проверены (`status: published`, источники, дата, редактор).
- [ ] Продукты проверены, указаны ПСК, сроки актуальности.
- [ ] Городские страницы прошли шлюз, `indexable: true` только у прошедших.
- [ ] Материалы гида с автором, редактором, источниками.

## Техника и SEO
- [ ] Собственный домен и хостинг в РФ; 301 со старых адресов; одна версия хоста, HTTPS.
- [ ] `NEXT_PUBLIC_BASE_PATH` пустой для домена, `siteUrl` обновлён.
- [ ] `indexing: true`, `mode: "production"`; сборка без ошибок валидатора и SEO-проверки.
- [ ] robots.txt и sitemap.xml в корне домена; Яндекс Вебмастер: права, robots, sitemap, переобход.
- [ ] Core Web Vitals на мобильных в норме.
