# Редакционная политика

- Только проверяемые сведения. У каждого условия — первичный источник (страница кредитора), дата проверки, срок актуальности и редактор, который его подтвердил.
- Ставка показывается вместе с диапазоном ПСК. Иные условия, влияющие на полную стоимость, раскрываются полностью или не показываются.
- Запрещено: выдуманные офисы, отзывы, рейтинги, ставки; «гарантированное одобрение», «лучший кредит» без воспроизводимой методики; копирование описаний банков без источника; массовые городские тексты с заменой топонима; скрытый текст.
- Машинный черновик всегда проходит проверку редактором.
- Городская страница публикуется партиями после подтверждения спроса, реальных предложений с региональной доступностью и уникального локального материала с источниками.
- Устаревшее скрывается автоматически (по `validUntil`) и пересматривается по плану (`reviewDue` у материалов).
- Партнёрские ссылки помечаются в карточке и раскрываются в тексте рядом с предложениями.
