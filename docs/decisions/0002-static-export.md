# ADR 0002. Статическая сборка Next.js

Статус: принято.

`output: "export"` — все страницы собираются в HTML заранее (SSG). Это даёт полный текст в исходном HTML, отсутствие сервера и простой хостинг. Список предложений рендерится при сборке тем же кодом, что и в браузере (`public/js/offers-render.js`), поэтому разметка совпадает. Поведение страниц (`public/js/site.js`) запускается после гидратации React. GSAP и шрифт Onest подключаются из npm, без внешних CDN.
